# M&E DfS Ontology

Interactive publication of the **M&E Design for Safety (DfS) Ontology**.

## Contents

- `ontology/ME_DfS_Ontology.owl` — the OWL ontology.
- `index.html` — the GitHub Pages landing page with an embedded WebVOWL visualization.

## GitHub Pages

After uploading these files to the repository, enable:

**Settings → Pages → Deploy from a branch → `main` → `/ (root)` → Save**

The public page will then be:

`https://olivia1412.github.io/M-E-DfS-Ontology/`

## WebVOWL

The visualization uses the WebVOWL service at:

https://service.tib.eu/webvowl/

The hosted ontology is passed to WebVOWL using its public GitHub Pages URL.

## Important

The ontology IRI in the supplied OWL file is retained:

`http://www.semanticweb.org/me-dfs`

The GitHub Pages URL is the publication location, not a replacement of the ontology IRI.
